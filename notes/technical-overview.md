This repo is all about handling PDF transcripts. It stores and manages transcript documents, making it easy for you to access them whenever needed.

## Key Features

- Stores transcripts as PDF files
- Organized in a simple structure for quick access

## Tech Stack

- Just PDF documents—no complex frameworks involved.

## Quick Start

To get started, follow these steps:

1. Clone the repo:

   ```bash
   git clone https://github.com/justin-napolitano/transcripts.git
   ```

2. Navigate to the cloned directory and find your PDF files.

## Project Structure

```
transcripts/
└── TEABYVLM.pdf  # Example transcript document 
```

## Gotchas

- There’s no search or indexing right now. Keep this in mind if you’re dealing with a lot of transcripts. Future updates aim to address this, along with better access and features.
